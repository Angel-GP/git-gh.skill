# git-gh v1.0.0

## 版本摘要

首个正式版本。内置 Windows x64 便携版 Git for Windows 与 GitHub CLI，所有 git/gh 命令通过 `start.bat` 在隔离环境中运行；首次加载自动 bootstrap，无密钥时自动生成专用密钥并只输出公钥。

本版本共包含 10 个提交，覆盖便携环境、认证、提交规范、密钥扫描、CI 校验、全局安装和自动打包发布。

## 新增

- 内置 PortableGit `2.56.0.windows.2` 与 GitHub CLI `2.102.0`，无需系统安装 Git/gh。
- `start.bat` 隔离 `HOME`、`GH_CONFIG_DIR`、`GIT_CONFIG_GLOBAL`，不污染系统配置和 SSH 目录。
- `start.bat --bootstrap` 自动创建 `home\` 目录树、校验环境，并在无密钥时生成 ed25519 密钥、输出公钥。
- 支持 SSH 与 HTTPS 两种认证方式；明确 SSH 是账号认证，非自己的公开仓库默认 HTTPS。
- 强制 Conventional Commits，内置提交信息校验。
- 授权分级：只读命令自动执行；add/commit/push/tag/release 等写操作必须展示命令、影响和风险并等待确认。
- 强制推送默认禁止，必须展示覆盖范围并二次确认。
- SemVer `vX.Y.Z` 版本规则与详细 release notes 生成。
- 密钥扫描覆盖工作区、暂存区、已跟踪文件、commit message 和分支名；自动跳过 `tools/` 与 `home/`。
- 提交前扫描、`.gitignore` 保护、私钥不读取/不打印/不提交。
- GitHub Actions `validate`：校验便携环境、PowerShell 语法、必需文件和已跟踪文件密钥扫描。
- 安装只支持全局 skill 目录，`install.ps1` 不再接受项目级目标。

## 修复

- 修复 `scan-secrets.ps1` 在仓库根目录等于 skill 根目录时无法排除 `tools/` 和 `home/` 的问题。
- 修复暂存区扫描 9630 个文件时逐文件启动 git 进程导致超时的问题；现在按相对仓库根前缀排除工具目录。
- 增加 `-Tracked` 扫描模式，适配 CI 干净 checkout。
- 修复一键安装使用 SSH 地址导致无密钥用户无法安装的问题，默认改为 HTTPS。
- 修复 README 混入开发者分享/维护内容的问题，精简为纯用户文档。
- 修复 `install.ps1` 允许项目级安装的问题，固定为全局 skill 目录。

## 破坏性变更

无。首个正式版本，不存在旧版本升级兼容问题。

注意：从本版本开始，安装目标固定为全局 `$env:DSH_HOME\skills\git-gh`，不再支持项目级安装。

## 升级 / 安装步骤

1. 备份或保留现有 `home\` 目录（包含密钥、gh 登录和 Git 配置）。
2. 安装或更新到全局目录：

   ```powershell
   $dst = if ($env:DSH_HOME) { Join-Path $env:DSH_HOME 'skills\git-gh' } else { Join-Path $HOME '.dsh\skills\git-gh' }
   git clone https://github.com/Angel-GP/git-gh.skill.git $dst
   # 已有目录时：
   # git -C $dst pull --ff-only
   ```

3. 首次加载时 Agent 会自动执行 `start.bat --bootstrap`；也可以手动验证：

   ```powershell
   & "$dst\start.bat" --check
   ```

4. 如果没有密钥，bootstrap 会输出公钥；把公钥添加到 <https://github.com/settings/ssh/new>。
5. 如需 gh API/Release 操作，运行：

   ```powershell
   & "$dst\start.bat" gh auth login
   & "$dst\start.bat" gh auth status
   ```
